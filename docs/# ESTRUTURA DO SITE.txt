# ESTRUTURA DO SITE

## Página única

Criar uma experiência de página única com navegação por seções.

A página deve possuir uma narrativa contínua.

## 01 — LOADER

Objetivo:

Criar expectativa e introduzir a identidade.

Elementos:

* Fundo verde;
* Palavra BRASIL;
* Elementos gráficos;
* Transição para Hero.

Duração máxima:

2,8 segundos.

Permitir pular ou reduzir a animação quando necessário.
